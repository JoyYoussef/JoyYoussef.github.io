COMP 401 · Research McGill University Health Centre Supervisor: Dr. James Tsui

MRI preprocessing pipeline for soft tissue sarcoma

A complete preprocessing pipeline for MRI scans of 102 patients with extremity soft tissue sarcoma. Raw hospital scans vary wildly in intensity between machines and protocols, so the pipeline standardizes them before any downstream model sees them. I compared several normalization strategies and measured how consistent each left the data, then wrote the results up as a journal style report.

  1. DICOM
  2. NIfTI
  3. TotalSegmentator
  4. N4 bias correction
  5. Normalization
  6. Evaluation
Python · min/max, z score & Nyúl histogram normalization · coefficient of variation · KL divergence
COMP 565 · Machine learning in genomics In progress · fall 2026

Bayesian polygenic risk scores

A polygenic risk score model built from scratch, using variational inference with a spike and slab prior over SNP effects. The prior lets the model decide which variants matter at all, which suits traits driven by a small number of real signals buried among many markers.

Python · Jupyter · variational inference · statistical genetics
